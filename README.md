### 🚀 About Me

I'm a Software Developer based in Prayagraj, India, with a strong focus on **native Android development** using **Kotlin**, **Java**, and **Firebase**. I also build with **React** and **TypeScript** on the web, so I move comfortably between mobile and web depending on what a project calls for.

I care about clean architecture (MVVM, Clean Architecture), readable code, and shipping things that actually work end to end — not just demos.

Currently pursuing my **MCA** at United Institute of Management, Prayagraj.
